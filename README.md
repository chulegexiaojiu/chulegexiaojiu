## 📌 置顶项目

### 🤖 [job-agent](https://github.com/chulegexiaojiu/job-agent)

> Windows 本地求职 Agent 工作台 —— 用 Agent 工作流把「刷岗位、海投」变成「逐岗核验、来源可查」的自动化流水线。

**一句话价值**：不让 AI 替你海投，而是让 AI 先证明每个岗位值得投 —— 浏览器采集、文档解析、联网研究、交叉核验全部由 Agent 编排，**默认不发送**，每一步都留有证据。

**关键词**：`Agent 工作流` · `本地 RAG` · `浏览器自动化采集` · `多源交叉核验` · `隐私优先（本地存储）`
